# Код и сборка

TypeScript со сборкой tsdown, по образцу `dsh-better-sidebar`. `lib/index.js` – Host (ESM, Node 24, из внешних импортов только `node:*`). `lib/client.js` – Client, обёрнутый в `window.__ModuleLoader__.load({ id: 'dsh-loadout-manager', factory })`; React берётся из таблицы модулей оболочки, CSS Modules собираются в один тег `<style data-plugin>`. Пакеты `@deepseek-ai/*` 0.2.2-rc.2 стоят в `devDependencies` ради типов, импортировать из них можно только типы. Контракт маршрутов общий для Host и Client – `src/shared/api.ts`. `lib/` коммитится, потому что бандл установлен ссылкой на репозиторий.
